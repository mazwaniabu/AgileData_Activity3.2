This activity automated the duplicate removal workflow by creating a Python pipeline that loads a raw CSV file, detects duplicate rows, removes them, and saves a cleaned version in the processed folder. The logic was modularized into clear functions and paired with automated tests to verify that duplicates are removed, output files are created, and error cases are handled. This made the data preparation process repeatable and dependable rather than a manual one-time task.

GitHub Actions supported continuous integration by running the tests and executing the pipeline on each update. Every push or pull request triggered the workflow, giving rapid feedback when something failed and confirming when changes were safe to merge. This immediate validation reduced the risk of broken logic entering the main branch and encouraged small, incremental improvements.

The activity reflects Agile Data Science principles by treating data cleaning as an iterative and testable process. The workflow encouraged incremental development, continuous testing, and collaboration through version control. The automated CI pipeline created a tight feedback loop, enabling quick adjustments and better teamwork. Overall, this approach improved reliability and maintained a clear trace of changes across each milestone.
